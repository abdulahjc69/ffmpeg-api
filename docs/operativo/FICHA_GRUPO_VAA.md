## CHECKLIST OPERATIVO

### Pre-venta
- [ ] Propuesta enviada
- [ ] Llamada de seguimiento (24h después)
- [ ] Propuesta V2 si necesaria
- [ ] Contrato enviado
- [ ] Instrucciones de pago enviadas

### Confirmación
- [ ] 30% recibido
- [ ] Confirmación oficial enviada al cliente
- [ ] Rooming list enviado
- [ ] Expediente actualizado en Notion

### Preparación (-30 días)
- [ ] Todos los hoteles confirmados por escrito
- [ ] Transporte confirmado
- [ ] Todos los guías confirmados
- [ ] Entradas Alhambra reservadas
- [ ] Otras entradas reservadas
- [ ] Seguro de viaje (si aplica) gestionado

### Operación (-14 días)
- [ ] Rooming list recibido completo
- [ ] Rooming enviado a todos los hoteles
- [ ] Conductor tiene itinerario completo
- [ ] Guías tienen horarios y punto de encuentro

### Semana de salida (-7 días)
- [ ] 70% cobrado
- [ ] Confirmación final con todos los proveedores
- [ ] Programa definitivo enviado al responsable del grupo
- [ ] Número de Abdu compartido con el responsable

### Cierre (post-viaje)
- [ ] Mensaje de agradecimiento enviado
- [ ] Solicitar valoración/opinión
- [ ] Margen real registrado en la ficha
- [ ] Expediente cerrado en Notion
- [ ] ¿Repetirán? Anotado en CRM
